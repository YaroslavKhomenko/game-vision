# game-vision

Описание идеи от автора: $ARGUMENTS

> Если после «Описание идеи от автора:» пусто или стоит нераскрытый плейсхолдер (Codex и другие среды его не подставляют) — возьми описание из сообщения пользователя. Поля frontmatter `argument-hint` и `disable-model-invocation` специфичны для Claude Code; в других средах игнорируй их.

## 1. Загрузи методологию

Прочитай целиком файл `Game_Vision_Instructions.md` из каталога этого skill (лежит рядом с этим `SKILL.md`).

- Раздел «Инструкции ИИ» — основной источник правил: источники и точность, порядок уточнений (максимум два раунда и до 5 вопросов), структура Vision, объём, проверка готовности.
- Раздел «Геймдизайнеру: как пользоваться» написан для человека — используй его только как контекст.

Ниже — только отличия работы через Claude Code / Codex от веб-чата. Разделы 2–3 этого файла имеют приоритет над методологией; всё остальное — строго по ней.

## 2. Адаптация под Claude Code / Codex

- Правило «Если получен только этот файл» означает: skill вызван без описания идеи (аргумент пуст и в сообщении нет описания). Попроси описать идею своими словами и ничего не создавай.
- Уточняющие вопросы задавай обычным текстовым сообщением, а не меню с вариантами ответа: ответы автора свободные.
- Источник сведений — только этот разговор. Не читай файлы проекта, память и другие skills, если автор сам не указал конкретный файл с материалами.
- Веб-поиск — только по правилам раздела 7 методологии.
- Не создавай код, HTML и другие файлы, кроме файла Vision (шаг 3) и демо, если автор отдельно попросил его по правилам раздела 8.
- Демо (только по отдельной просьбе автора) сохраняй как `<slug>-demo.html` рядом с Vision, в разделе 8 укажи его имя файла и назначение, затем пересохрани и выведи Vision целиком.

## 3. Выдача

Каждый раз, когда выдаёшь Vision (сразу, после уточнений, по команде «Собери по имеющимся данным», по исчерпании времени или после правок):

1. Сохрани Vision в текущую рабочую папку как `<slug>-vision.md`. `slug` — название игры транслитом латиницей в kebab-case; если названия нет — `untitled-game`.
   - При правках в этом разговоре перезаписывай тот же файл целиком. Если в правках появилось или изменилось название — переименуй этот файл под новый slug, старую копию не оставляй.
   - Если файл с таким именем уже существовал до этого разговора — не трогай его, сохрани с суффиксом `-2`, `-3` и т. д.
2. В ответе выведи Vision целиком по правилам методологии (только Markdown, без вступления, отчёта о проверке и рекомендаций, не в блоке кода). Единственное дополнение — после документа пустая строка и строка `Сохранено: <путь к файлу>`.
